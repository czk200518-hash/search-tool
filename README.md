# search-tool
基于py的本地文件搜索工具，方便我自己汇总大量的工程文件所制作的

能定向检索近100种文件格式，也支持手动添加格式。手动添加的自定义文件格式会保存到配置文件中，下次启动仍可保留。


程序的核心检索逻辑位于perform_search 中的嵌套函数search_directory。该函数使用os.scandir递归遍历目录树，对每个文件和文件夹进行匹配判断使用Python标准库，在Windows、macOS、Linux上均可运行（大概，我没测试过）。搜索结果会动态显示，进度条、扫描速度、耗时等信息会在臊面的过程中实时更新，检索操作在后台处理，可随时停止检索。

双击打开检索出的文件或者文件夹，右键菜单可复制其路径或打开其所在文件夹。也可将结果导出为TXT或CSV文件，便于记录。
经实测，检索最大速度可达近10w文件/s，不过实际使用可能受电脑配置、目录层级、检索关键词等因素，平均使用只有三四万的速度（我自己的电脑）

目前格式过滤使用endswith，对于“.tar.gz”这种复合扩展名，仅判断末尾的.gz“”可能导致误判（例如“file.tar.gz”经过滤，“.gz”会被匹配，但实际可能想匹配“.tar.gz”）。虽然有预处理，但未完全处理多级扩展名。
此外匹配模式仅限于包含或精确匹配，不支持通配符或正则表达式。
